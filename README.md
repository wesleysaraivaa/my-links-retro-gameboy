# Wesley Saraiva - Links

Página de links pessoais com estética de Game Boy retrô interativo.

## Tecnologias

- React 19 + TypeScript
- Vite
- Tailwind CSS
- React Router DOM
- Lucide React

## Funcionalidades

- Console Game Boy interativo com controles clicáveis
- Suporte a teclado (setas direcionais, Enter, Espaço, Escape)
- Navegação por menu de links
- Trilha sonora ambiente e efeitos sonoros via Web Audio API
- Tela de boot animada
- PWA instalável

## Como executar

```bash
npm install
npm run dev
```

## Build para produção

```bash
npm run build
```
